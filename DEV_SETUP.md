# DEV_SETUP.md — BidReady

## 1. Prerequisites

| Tool | Version | macOS install |
| --- | --- | --- |
| Git | any recent | `xcode-select --install` |
| Python | 3.12 | installed by uv automatically |
| uv | latest | `brew install uv` |
| Node.js | 22 LTS | `brew install node@22` |
| pnpm | 9+ | `corepack enable && corepack prepare pnpm@latest --activate` |
| make | system | preinstalled on macOS |
| Tesseract | 5+ (optional) | `brew install tesseract` — only for scanned (image-only) tenders |

No LibreOffice is needed: PDFs are rendered with PyMuPDF. An Anthropic API key is optional: without one,
set `LLM_PROVIDER=offline` and the rule-based engine handles extraction and drafting.

## 2. First-time setup

```bash
git clone <repo-url> bidready && cd bidready
cp .env.example .env     # edit JWT_SECRET, ADMIN_EMAIL, ADMIN_PASSWORD (+ ANTHROPIC_API_KEY for Claude)
make setup               # uv sync + pnpm install + migrations + embedding model download (~130 MB, once)
make seed-demo           # optional: demo company, knowledge base and a drafted sample project
make dev                 # backend :8000 + frontend :5173
```

Open http://localhost:5173 and sign in with `ADMIN_EMAIL` / `ADMIN_PASSWORD`. The admin is created on the
first start when the database has no users. All paths in `.env` are relative to the repo root.

## 3. Environment variables

The backend reads `.env` from the repo root (`backend/app/core/config.py`); Vite reads only `VITE_*`.
Put comments on their own line — never after a value. Real environment variables override `.env`.

| Variable | Default | Purpose |
| --- | --- | --- |
| `APP_ENV` | development | `production` serves `frontend/dist` from the API port |
| `LOG_LEVEL` | INFO | DEBUG, INFO, WARNING, ERROR |
| `API_HOST` / `API_PORT` | 127.0.0.1 / 8000 | Backend bind address (used by `make dev-backend`/`start`) |
| `CORS_ORIGINS` | http://localhost:5173 | Only needed without the Vite proxy |
| `DATA_DIR`, `DATABASE_URL`, `FILES_DIR` | `./backend/data…` | Local database and files (gitignored) |
| `MAX_UPLOAD_MB` | 50 | Per-file upload limit |
| `JWT_SECRET` | — | Session signing key: `python3 -c "import secrets;print(secrets.token_urlsafe(48))"` |
| `JWT_EXPIRE_MINUTES` | 720 | Session length |
| `ADMIN_EMAIL` / `ADMIN_PASSWORD` / `ADMIN_NAME` | — | First user, seeded when no users exist |
| `LLM_PROVIDER` | auto | `auto` = Claude if a key is set, else offline; `anthropic`; `offline` |
| `LLM_MODEL` | claude-opus-5-5 | Claude model ID |
| `LLM_EFFORT` | medium | low, medium, high (Opus 5.5 has no temperature) |
| `ANTHROPIC_API_KEY` | — | Required for `anthropic` |
| `LLM_MAX_CONCURRENCY` | 8 | Parallel model calls while drafting |
| `LLM_MAX_TOKENS_PER_PROJECT` | 2000000 | Hard token cap per project |
| `LLM_TIMEOUT_SECONDS` | 120 | Per-request timeout |
| `EMBEDDING_PROVIDER` | fastembed | `fastembed` (bge-small, local) or `hash` (no download) |
| `EMBEDDING_MODEL` | BAAI/bge-small-en-v1.5 | fastembed model |
| `RETRIEVAL_MIN_SCORE` | 0.35 | Below this, a requirement is a gap without drafting (hash vectors use 0.12) |
| `RETRIEVAL_TOP_K` | 6 | Evidence chunks per requirement |
| `OCR_ENABLED` / `TESSERACT_CMD` | true / tesseract | OCR for scanned pages |
| `JOB_WORKERS` | 2 | Background worker threads |
| `VITE_API_BASE_URL` | /api | API base for the frontend |

The full annotated template is [.env.example](.env.example).

## 4. Everyday commands

| Command | What it runs |
| --- | --- |
| `make setup` | `uv sync` · `pnpm install --frozen-lockfile` · `make migrate` · `make prefetch` |
| `make dev` | backend (`uvicorn --reload` on :8000) and frontend (`pnpm dev` on :5173) together |
| `make dev-backend` / `make dev-frontend` | one side only |
| `make check` | lint + typecheck + tests for both apps (must pass before ticking a task) |
| `make lint` / `make format` / `make typecheck` / `make test` | ruff + ESLint + Prettier / auto-format / mypy + tsc / pytest + vitest |
| `make migrate` | `alembic upgrade head` (also runs automatically at startup) |
| `make migration m="add x"` | new autogenerated Alembic revision — review before migrating |
| `make gen-api` | regenerate `frontend/src/types/api.ts` from the backend schema (no server needed) |
| `make samples` | regenerate the fictional demo tender, corrigendum and company documents in `samples/` |
| `make seed-demo` | load the demo company, knowledge base and one analysed + drafted project |
| `make demo-reset` | delete `backend/data` and reseed — for rehearsals |
| `make nlp-company` | generate + load the sample IT/AI company pack (keeps your company name, backs up the old profile) |
| `make eval` | requirement-extraction recall/precision on `samples/` with the configured provider |
| `make build` / `make start` | build the frontend / serve API + UI on :8000 in production mode |
| `make clean-data` | delete `backend/data` (asks first) |

Single tests: `cd backend && uv run pytest tests/api/test_flow.py -k addendum` ·
`cd frontend && pnpm test src/features/matrix` (watch mode: `pnpm test:watch`).

## 5. Troubleshooting

| Symptom | Fix |
| --- | --- |
| Analysis fails with "The Anthropic API key was rejected" although `.env` has no key | Your shell exports `ANTHROPIC_API_KEY`, which overrides `.env`. Set `LLM_PROVIDER=offline` in `.env`, or export a valid key. |
| Every requirement is a gap | The knowledge base is empty or still indexing; upload documents and wait for "Ready" |
| Scanned PDF yields no requirements | Install Tesseract and keep `OCR_ENABLED=true` |
| First drafting run is slow | The embedding model is downloading; `make prefetch` does it ahead of time |
| No internet at the venue | Run `make prefetch` beforehand, or set `EMBEDDING_PROVIDER=hash` and `LLM_PROVIDER=offline` |
| 401 on every API call in dev | Use http://localhost:5173 (proxy), not :8000 directly from another origin |
| `database is locked` | Stop duplicate backend processes; SQLite allows one writer |
| Frontend types out of date | `make gen-api` |
